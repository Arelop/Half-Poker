# ♠ Покер с друзьями

Онлайн **Техасский холдем** (No-Limit) для игры компанией. Каждый заходит по
ссылке со своего телефона или ноутбука — карты у каждого свои и скрыты от
остальных, как в настоящем покере.

## Как запустить

```bash
npm install      # один раз — поставить зависимости
npm start        # запустить сервер
```

В консоли появятся адреса, например:

```
   http://localhost:3000
   http://192.168.1.19:3000
```

Открой `http://localhost:3000` у себя, нажми **«Создать стол»** — получишь
4-буквенный код. Друзья вводят этот код (или переходят по ссылке из кнопки с
кодом сверху) и садятся за стол.

## Как играть с друзьями

**В одной Wi-Fi сети (дома):**
дай друзьям ссылку с твоим IP из списка выше (не `localhost`, а вида
`http://192.168.1.19:3000`). Работает сразу, ничего настраивать не надо.

**Через интернет (друзья в разных местах):**
проще всего пробросить порт туннелем. Например, поставив
[cloudflared](https://developers.cloudflare.com/cloudflare-tunnel/) или
[ngrok](https://ngrok.com/):

```bash
npx localtunnel --port 3000      # выдаст публичную ссылку вида https://xxx.loca.lt
# или
ngrok http 3000
```

Публичную ссылку раздай друзьям — заходят из любой точки.

## Правила и возможности

- **Техасский холдем**, безлимит: 2 карты в руку, 5 общих на столе.
- Малый/большой блайнды и стартовый стек настраиваются при создании стола.
- Кнопка дилера, блайнды, круги торговли (префлоп/флоп/тёрн/ривер).
- Действия: **пас, чек, колл, бет/рейз** (со слайдером и пресетами ½ банка /
  банк / олл-ин) и **олл-ин**.
- Корректные **сайд-поты** при олл-инах с разными стеками.
- Вскрытие с раскрытием карт и определением победителя (сплит-поты делятся,
  лишняя фишка идёт первому слева от баттона).
- До **9 игроков** за столом.
- **Переподключение**: обновил страницу или пропал интернет — вернёшься на своё
  место с теми же фишками (пока раздача не кончилась).

## Структура проекта

```
server.js              — HTTP + Socket.IO сервер, раздаёт статику
src/
  deck.js              — колода и криптостойкое тасование
  handEvaluator.js     — оценка лучшей комбинации из 7 карт
  game.js              — движок раздачи: блайнды, торговля, сайд-поты, вскрытие
  rooms.js             — менеджер комнат (код → стол)
public/
  index.html, style.css, client.js   — интерфейс: лобби и покерный стол
```

## Разработка

```bash
npm run dev      # автоперезапуск при изменении файлов (node --watch)
```
